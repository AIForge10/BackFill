Notes
Rerun vs committed. The nine registered variants were rerun with run_all.py --variant <name> --cache data/raw/prices/is-v4. The default cache data/raw/prices/is records unresolved download failures, so the guardrail refuses it. Rows tagged committed are the frozen working candidate's published results. They were not rerun, because the frozen licensed cache (data/raw/prices/final_candidate_v1) is not present locally.
Metrics. Sharpe and returns are portfolio-level and include idle cash. A lot's return is net P&L on its entry notional, excluding hedge carry. Placebo uses unmatched FDA-page non-listed controls, which is not a causal estimate. The p-values are HAC. Nine variants were tested, so a single p below 0.05 would not survive a multiple-testing correction.
